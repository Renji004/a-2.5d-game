# a-2.5d-game
一个2.5d视角游戏/A small 2.5D game
使用 HTML5 Canvas 开发的等距视角生存小游戏。
人工指导+AI编写

## 内容
2.5D 等距视角
无限世界（区块动态加载）或有限世界
水域减速机制
四种敌人
几种动物
昼夜循环（120s）
远程 / 近战 双模式
自动存档与成就系统
支持自定义角色贴图（详情见游戏内“关于”）

## 操作方式
鼠标左键：移动（自动寻路）
Ctrl：切换远程/近战模式
空格：近战攻击
ESC：暂停/存档
